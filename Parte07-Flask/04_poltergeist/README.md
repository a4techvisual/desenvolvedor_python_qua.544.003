# Git Poltergeist v2.0 — WebView

Interface feita com **pywebview**, usando HTML/CSS/JavaScript dentro de uma janela nativa.

- Memoriza a pasta do projeto.
- Abre e executa o Auto Commit automaticamente.
- `git add .`
- `git commit -m "Commit DD/MM/AAAA"`
- `git push origin <branch>`
- Mostra o link real do GitHub (`origin`).
- Botão **Mudar pasta** somente quando você quiser trocar o projeto.

Instalação: `pip install -r requirements.txt`

Gerar EXE: execute `build_exe.bat`.
